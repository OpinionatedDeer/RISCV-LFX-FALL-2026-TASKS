**Coding Challenge \- Implementation of Tightly-Coupled Data-Flow Integrity in RISC-V**

Pick one challenge based on your profile:

\- Hardware: Write a SystemVerilog module for a 4-entry, 32-bit Content Addressable Memory (CAM). Include a testbench verifying correct match/miss signals.

\- Software: Write an LLVM pass (in C++) that iterates over all functions in a module, counts memory load/store instructions, and prints the result. Provide a small C program and a script to run your pass.
